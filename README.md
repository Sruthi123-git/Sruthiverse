# 🛍️ SruthiVerse - Online Shopping Store

Welcome to **SruthiVerse**, my E-commerce Django Project! A complete online shopping website built with Python & Django.

## ✨ Features
- 👤 User Registration & Login
- 🏠 Home Page with Products
- 🛒 Shopping Cart
- 💳 Checkout & Success Page
- 📱 Responsive Design

## 🛠️ Tech Stack
- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite
- **Version Control:** Git & GitHub

## 🚀 How to Run Locally
1. Clone the repo:
   `git clone https://github.com/Sruthi123-git/Sruthiverse.git`
2. Go to project folder:
   `cd ecommerce_project`
3. Install dependencies:
   `pip install django`
4. Run server:
   `python manage.py runserver`
